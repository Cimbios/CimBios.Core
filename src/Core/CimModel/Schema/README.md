# CimBios.Core.CimModel.Schema

CimBios.Core.CimModel.Schema is a library that constructs a meta model of linked data (RDF) based on schemas. It is used to build a strongly typed `CIM (IEC61970)` model in [CimBios.Core libraries](https://github.com/Cimbios/CimBios.Core).

### Supported serializers
- RDF-XML
